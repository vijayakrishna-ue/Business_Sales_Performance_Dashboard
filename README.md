# Business_Sales_Performance_Dashboard
A four-page interactive Power BI Dashboard created using a fictional dataset of 4,196 entries to analyze sales, profitability, employee performance, regional trends and performance against targets.

Designed dedicated views for Executive Overview, Employee Performance, Product & Profitability, and Targets & Geography. Created DAX measures and KPIs to track Net Sales, Profit, Profit Margin, Orders, Target Achievement, and other key business metrics. Analyzed performance across employees, products, regions, and time periods, highlighting trends and variances against targets. Built a structured data model with relationships across multiple tables, enabling accurate cross-functional analysis and reporting. Performed data cleaning and transformation using Power Query to prepare raw data for analysis and ensure consistency across dashboard visuals.
